# CodeAlpha Hangman Game 🎮

## About
A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- 5 predefined words
- Maximum 6 wrong attempts
- One-letter-at-a-time guessing
- Input validation
- Win and Game Over conditions

## Technologies Used
- Python
- Random module
- While loop
- If-else
- Lists
- Strings

## How to Run

```bash
python hangman.py
